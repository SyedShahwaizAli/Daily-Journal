# Daily-Journal
A simple command-line journal application that helps you maintain a daily diary of your thoughts, moods, and activities. Perfect for maintaining a GitHub contribution streak while building a meaningful personal record.

## Features

- Add daily journal entries
- Track your mood and activities
- View entries by date
- Search through past entries
- List all entry dates
- Automatic date tracking
- JSON-based storage

## Usage

1. Run the application:
```bash
python main.py
```

2. Choose from the following options:
   - Add new entry (1)
   - View today's entry (2)
   - View entry by date (3)
   - Search entries (4)
   - List all dates (5)
   - Exit (6)

## File Structure

- `main.py` - Command-line interface and application entry point
- `journal.py` - Core journal functionality and data management
- `entries.json` - Data storage file (created automatically)
